\# Sistema Casa de Leilões



\## Sobre o Projeto

Este projeto trata-se de um sistema informatizado desenvolvido para otimizar as rotinas de uma casa de leilões. A aplicação permite realizar o cadastro e a listagem de produtos, controlando dados importantes como valores e o status atualizado de cada item (ex: A Venda, Vendido).



\## Tecnologias Utilizadas

\- \*\*Linguagem:\*\* Java (Interface gráfica em Java Swing)

\- \*\*Banco de Dados:\*\* MySQL

\- \*\*IDE:\*\* Apache NetBeans

\- \*\*Versionamento:\*\* Git e GitHub
